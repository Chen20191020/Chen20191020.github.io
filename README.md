# Chen Qian — Academic Website

A minimalist, responsive academic website hosted on GitHub Pages.

## Pages

- `index.html` — biography, research interests, publication and education (no separate research-highlights section)
- `research.html` — publication, manuscripts and research projects
- `experience.html` — teaching, professional experience and awards
- `software.html` — research code (without a technical-skills section)
- `assets/Chen_Qian_CV.pdf` — the original PDF uploaded on 2026-10-16, linked directly from the CV navigation item
- `cv.html` — a compatibility redirect to the PDF for old links, including those printed in earlier CVs

## Design and deployment

Shared styling lives in `assets/styles.css`. The white-and-slate-blue design is deliberately minimal. Update on `main` to deploy through GitHub Pages.
